# Nestor 1.4.0

Офлайн-расшифровка и разбивка по спикерам для русской речи на процессоре.
Без интернета, без токенов и подписок.

## Что нового

**Словарь терминов.** Nestor слышит аббревиатуры и термины так, как их
произносят: «докер», «днс», «айпи адрес», «кубернетес». С включённой галочкой
«Исправлять термины по словарю» он заменяет такие формы на канонические —
`Docker`, `DNS`, `IP-адрес`, `Kubernetes`. Словарь из 119 терминов покрывает
четыре области: разработку, ИТ-инфраструктуру, виртуализацию и сотовую связь
(GSM / LTE / 5G).

Это чисто текстовая замена, а не догадка: Nestor меняет только то, что нашлось
в словаре, не придумывает новые слова, работает офлайн и не влияет на скорость
распознавания.

**Почему текст, а не подсказки декодеру.** Мы измерили и вариант с подсказками
акустической модели (sherpa-onnx hotwords). Он дал мизерный прирост, стоил
примерно 1,5× времени декодирования и иногда портил верные слова. Текстовая
замена оказалась и полезнее, и бесплатной — в поставку пошла она.

**Свой словарь.** Файл `hotwords.yaml` в каталоге данных
(`%LOCALAPPDATA%\Nestor` на Windows) заменяет встроенный; в командной строке —
`nestor transcribe meeting.mp3 --glossary --glossary-path my_terms.yaml`. Формат —
пары «термин + услышанные формы»:

```yaml
- term: "Docker"
  aliases: ["докер"]
- term: "IP-адрес"
  aliases: ["айпи адрес", "айпи"]
```

Настройка по умолчанию выключена.
