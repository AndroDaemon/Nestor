# Nestor 1.5.2

Офлайн-расшифровка и разбивка по спикерам для русской речи на процессоре.
Без интернета, без токенов и подписок.

## Что нового

### Многочасовые записи больше не падают

Пятичасовые файлы раньше заканчивались ошибкой `bad allocation` — не хватало
памяти. Причина была в том, что подготовка звука и диаризация держали в памяти
несколько полных копий волны (по ~1.2 ГБ каждая на пятичасовой записи).

Теперь:

* **Подготовка звука идёт без многогигабайтных копий** — фильтр высоких частот
  пишет результат на месте, уровень речи считается чанками. Пик памяти упал
  примерно с 6 ГБ до 1.2 ГБ.
* **Диаризация идёт перекрывающимися блоками** по 20 минут (перекрытие 60 с),
  после чего ярлыки спикеров сшиваются между блоками по голосовым эмбеддингам.
  Пик памяти — около 1.8 ГБ независимо от длительности записи.

Пятичасовой файл, который раньше не расшифровывался совсем, проходит целиком.

### Интерфейс

* **Столбец спикеров справа.** Спикеры переехали из строки над таблицей в
  вертикальную колонку: сортировка по числу реплик (самые разговорчивые
  вверху), видно число реплик с полоской загруженности и уверенность узнавания
  по сохранённому голосу. Кнопки 🎙 / ⇊ / ⇄ больше не «убегают» от курсора.
* **Расшифровка на всю ширину** — список реплик занимает всё место между
  панелью записей и спикерами, а название записи остаётся на экране при
  прокрутке (липкая шапка).
* **Панель записей сворачивается** — кнопка « в её углу (или Ctrl+B) убирает
  список в узкую колонку с одними кнопками; состояние запоминается.
* **Волна точнее на длинных записях** — число точек следует длительности
  (около четырёх в секунду вместо фиксированных 1200 на всю запись), а клик по
  волне переходит к ближайшей границе реплики.
* **Уведомление о готовности** снова содержит текст («Расшифровка завершена: …»)
  вместо пустого «Новое сообщение».

## Обновление

Установите `Nestor-Setup-1.5.2.exe` поверх прежней версии. Настройки,
расшифровки и сохранённые голоса в `%LOCALAPPDATA%\Nestor` сохраняются.
