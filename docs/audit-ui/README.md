# Пакет для аудита UI/UX — Nestor 1.5.3

Этот каталог — всё, что нужно аудитору, чтобы **запустить продукт и оценить
интерфейс**, не собирая проект из исходников и не разбираясь в коде.

Дата подготовки: 17.11.2026. Версия продукта: **1.5.3**.

| Файл | Для чего |
|---|---|
| `brief.md` | Бриф: что за продукт, для кого, что важно, что оценивать |
| `checklist.md` | Чек-лист: экран за экраном, вопросы и критерии |
| `stand.md` | Как запустить стенд: установщик, портативная сборка, демо-данные |
| `../ui-map.md` | Карта интерфейса: названия всех зон и элементов |

## Порядок работы аудитора

1. Прочитать `brief.md` — понять продукт, аудиторию и рамки аудита.
2. Поднять стенд по `stand.md` (или запустить уже собранный exe).
3. Пройти `checklist.md` по экранам, отмечая проблемы.
4. Сверяться с `../ui-map.md`, чтобы в отчёте называть зоны и элементы
   однозначно (например: «в **шите**, в **панели спикеров**, кнопка **↩**»).

## Рамки аудита (что входит и что нет)

**Входит:**
- Веб-интерфейс приложения: главный экран, рейл записей, шит записи,
  панель спикеров, док плеера, модалки, тосты, диалоги повторного прохода.
- Информационная архитектура, читаемость, доступность с клавиатуры,
  понятность состояний (пустое, загрузка, ошибка, готово).
- Тексты интерфейса (русский), их ясность и единообразие.

**Не входит:**
- Качество распознавания и точность диаризации (отдельная тема,
  см. `../rukovodstvo.md`).
- Внутренняя архитектура, код, производительность движков.
- Установщик/инсталляция как UX-сценарий (только поверхностно).

## Чего просить не нужно

Продукт умышленно минималистичен и офлайн. Это **не** репорт как баг:
- отсутствие облачной синхронизации, аккаунтов, темы-переключателя;
- отсутствие мобильной версии — продукт настольный под Windows;
- русскоязычный интерфейс без локализации на другие языки;
- «скромное» визуальное оформление: один файл без фреймворков.
