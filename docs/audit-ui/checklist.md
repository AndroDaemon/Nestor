# Чек-лист аудита UI/UX — Nestor 1.5.3

Идти по экранам сверху вниз. Названия зон — из `../ui-map.md`, чтобы в отчёте
можно было однозначно указать место. Под каждым блоком — вопросы; отвечать
кратко («ок» / «проблема: …»). Серьёзность: **Б** — блокирует, **М** — мешает,
**Ш** — шероховатость, **П** — пожелание.

Стенд: `stand.md`. Если запуска нет — можно оценить по скриншотам и по
`../ui-map.md`, но живые состояния (прогресс, ошибка) важны.

---

## A. Общая рамка (весь экран)

- [ ] Понятно ли за 5 секунд, что это за приложение и что с ним делать?
- [ ] Не путает ли **трёхколоночная раскладка** (рейл → текст → спикеры)?
- [ ] Есть ли визуальный «хозяин» экрана — куда смотреть первым?
- [ ] Согласованы ли отступы, шрифты, размеры кнопок между зонами?
- [ ] Работает ли на 1366×768? Не режет ли панель спикеров текст?
- [ ] На широком экране (1920+) — не растянуто ли пустотой?
- [ ] Тёмная тема: достаточен ли контраст текста, статусов, полосок?
- [ ] Масштабирование шрифта ОС (125–150 %) не ломает раскладку?

## B. Топбар

- [ ] Понятно ли, что **поиск** ищет по тексту записи, а не по записям?
- [ ] Виден ли **счётчик совпадений** и понятен ли переход Enter?
- [ ] Меню **«Выгрузить»** — очевидны ли форматы (Word/Текст/Markdown/
      SRT/VTT/Данные)? Понятно ли, чем `.srt` отличается от `.vtt`?
- [ ] «Копировать текст» — не теряется ли среди форматов?

## C. Рейл (библиотека записей)

- [ ] Понятна ли **карточка записи**: имя, точка статуса, короткий статус?
- [ ] Различимы ли состояния: `done` / `working` / `error` / `cancelled` /
      «не расшифрована»? Цвета точек не путаются?
- [ ] Понятен ли **короткий статус** на карточке («ошибка · 78 %»,
      «остановлено», «стадия · N %»)?
- [ ] **Подсказка карточки** (многострочный тултип): не перегружена ли?
      Доходит ли до пользователя, что подробности там?
- [ ] Виден ли процесс: двигается ли процент у работающих записей?
- [ ] Понятен ли **фильтр «⚑»** (только в работе и с ошибкой)?
- [ ] Понятен ли **фильтр по имени**?
- [ ] Кнопка **«+»** («Добавить файлы…») — очевидна?
- [ ] Кнопка **сворачивания рейла** («/») — находится ли, ясен ли смысл?
- [ ] Кнопка **«?»** (помощь) — заметна ли?
- [ ] Пустое состояние («Пока пусто») — подсказывает ли, что делать?

## D. Главный экран

- [ ] **Дропзона**: понятно ли, что можно и кликнуть, и перетащить?
      Виден ли прогресс выгрузки («Загрузка «имя» — N %»)?
- [ ] Блок настроек: не перегружен ли? Что спрятано в **«Дополнительно»** —
      не спрятано ли слишком важное?
- [ ] **«Разбить по говорящим» / «Без разбивки»** — понятен ли выбор
      неспециалисту?
- [ ] **«Сколько человек в записи»** — ясно ли, когда ставить «автоматически»,
      а когда число?
- [ ] **«Подставлять знакомые имена»** + счётчик + кнопка **«Голоса»** —
      связь между тумблером и библиотекой голосов понятна?
- [ ] **«Объединять похожие голоса»** (выключено/обычно/осторожно) —
      понятны ли три режима без объяснений?
- [ ] «Исправлять термины по словарю» и кнопка **«Словарь»** — доступно ли
      управление словарём?
- [ ] «Начинать расшифровку немедленно» — ясно ли, что иначе запись ждёт?
- [ ] «Звуковой сигнал по окончании» — заметно ли, что он по умолчанию выкл.?

## E. Модалка «Голоса»

- [ ] Понятно ли, зачем сохранять голос и что произойдёт на будущих записях?
- [ ] Различимы ли голоса (имя, дата обновления, заметка)?
- [ ] Понятны ли **пороги узнавания** («Насколько уверенно узнавать»,
      «Не путать похожие голоса», «Сверять по всей записи») — для
      неподготовленного пользователя?
- [ ] Экспорт/импорт голосов — очевиден? Понятен ли отчёт импорта?

## F. Шит (экран записи) — шапка и результат

- [ ] **Имя файла** и подпись: читается ли строка бейджей
      (длительность · модель · RTF · N реплик)?
- [ ] **«узнал X из Y спикеров»** — понятен ли смысл без объяснения?
- [ ] **Строка результата** «Найдено N говорящих · без имени: K» —
      понятна ли связь с панелью спикеров?
- [ ] Кнопка **«Распознать спикеров заново»** — ожидаемый ли результат
      ясен до нажатия?
- [ ] **Индикатор сохранения** («сохраняю…» / «сохранено» /
      «не сохраняется — повторю») — замечается ли? Понятен ли третий текст?

## G. Шит — панель спикеров (ключевая зона)

- [ ] Понятно ли, что панель справа — это список говорящих текущей записи?
- [ ] **Строка ярлыка** (имя + счётчик реплик + полоска) — читается ли
      без инструкции? Полоска = «сколько говорит» — очевидно?
- [ ] Число реплик: помогает или шумит? Не сдвигает ли строку ввод имени?
- [ ] **Название панели «Спикеры (XX / YY)»** — понятно ли, что XX —
      участники, YY — «подозревается шум»? Нужен ли тултип, достаточен ли он?
- [ ] Кнопки **🎙 (голос)**, **⇊ (склеить)**, **⇄ (переименовать всюду)** —
      различимы ли, понятны ли без тултипов?
- [ ] Клик по цветному квадрату = **фильтр по спикеру** — обнаруживаемо ли?
- [ ] Как выглядит **дублирующееся имя** (жёлтая кромка + точка) — понятно
      ли, что предлагается склеить?
- [ ] **Группа «Фон»** («▸ Фон · N»): понятно ли, что там мелкие ярлыки и шум?
      Ясна ли кнопка **↩** (вернуть)? Ясен ли режим пометки **«+»**?
- [ ] Сортировка (самый разговорчивый вверх) — не «прыгают» ли строки
      после переименования и не раздражает ли это?
- [ ] При 15–30 ярлыках панель: обозрима? Нужна ли в ней прокрутка/поиск?

## H. Шит — лента реплик

- [ ] Читается ли реплика: **время**, **имя спикера**, **текст**?
- [ ] Понятно ли, что текст можно править прямо здесь (contenteditable)?
      Заметен ли режим правки (подсветка)?
- [ ] **Панель действий реплики** (закладка, подклеить, разделить,
      к спикеру…) — находится ли на hover? Не спрятана ли слишком?
- [ ] Понятны ли действия «подклеить» / «разделить» без подсказок?
- [ ] **Выделение реплик** (клик / Ctrl+клик / Shift+клик) и панель
      «Выделено: N реплик» — обнаруживаемо ли?
- [ ] **Поиск по тексту**: подсветка совпадений, переход по Enter — понятно?
- [ ] **Фильтр по спикеру** и строка «Только «Имя» — реплик: N» — понятно?
      Что даёт «▶ подряд» (соло-проигрывание)?
- [ ] Пустые состояния («В записи нет речи» / «У этого спикера нет реплик»)
      — информативны?
- [ ] Правка/перерисовка не «сбивает» ли пользователя (потеря каретки,
      скачок прокрутки)?

## I. Док плеера

- [ ] Понятна ли **волновая диаграмма**: где речь, где спикеры (цветные
      линейки), где закладки?
- [ ] Перемотка кликом по волне / по времени — обнаруживаемо?
- [ ] **Зум и прокрутка** таймлайна (Ctrl+колесо, колесо, драг) —
      найдёт ли пользователь эти жесты?
- [ ] **«Следовать за речью»** — заметно ли, что включено и что делает?
- [ ] Скорость (0.75×…2×) — нужна ли, доступна ли?
- [ ] Полоса иконок выгрузки — не дублирует ли меню топбара, не путает ли?
- [ ] Список **закладок** — понятен ли, как закладка появляется?

## J. Всплывающие и служебные

- [ ] **Модалки** («От чего зависит результат», «Приватность…», «Голоса»,
      «Словарь», диалог повторного прохода): закрываются ли очевидно?
      Читаемы ли объёмы текста?
- [ ] **Диалог повторного прохода** (full/transcribe/speakers) —
      понятна ли разница режимов и их последствия (что сохранится,
      что потеряется)?
- [ ] **Тосты** (в т.ч. с кнопкой «Вернуть») — замечаются ли? Успевает ли
      пользователь нажать «Вернуть» (7 с)?
- [ ] **Тултипы** — не мешают ли? Не дублируют ли видимое?

## K. Клавиатура и доступность

- [ ] Доступны ли основные действия **без мыши** (Space, ←/→, Ctrl+F,
      Ctrl+E, Ctrl+Z, J/K, Enter, Esc)?
- [ ] Видна ли **рамка фокуса** на интерактивных элементах?
- [ ] Не ловит ли перехват клавиш ввод в текстовом поле?
- [ ] Осмысленны ли **подписи для скринридера** (alt/aria) у иконок-кнопок?

## L. Тексты и микро-копирайтинг

- [ ] Нет ли в интерфейсе **жаргона разработчика** (диаризация, кластер,
      эмбеддинг, RTF)? Если есть — нужен ли он пользователю?
- [ ] Единообразны ли термины: «спикер»/«говорящий»/«участник»?
- [ ] Понятны ли формулировки ошибок (что делать после ошибки)?
- [ ] Нет ли «пустых» сообщений («что-то пошло не так»)?

## M. Нагрузка длинной записью (если есть многочасовая)

- [ ] При сотнях реплик: интерфейс остаётся отзывчивым на прокрутку?
- [ ] Видно ли на длинных стадиях, что процесс жив (полоса/процент/ETA)?
- [ ] При десятках спикеров панель остаётся удобной?
- [ ] Поиск по длинному тексту работает предсказуемо?
