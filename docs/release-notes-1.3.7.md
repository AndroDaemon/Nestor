# Nestor 1.3.7

Офлайн-расшифровка и разбивка по спикерам для русской речи на процессоре.
Без интернета, без токенов и подписок.

## Что нового

**Диаризация получает свой бюджет потоков.** На замерах выяснилось, что
разбивка по спикерам от лишних ядер только медленнее: кластеризация
агломеративная, её стоимость растёт примерно как квадрат числа речевых
сегментов. Теперь «Автоматически» даёт диаризации не больше 4 ядер
независимо от общего числа, а распознавание по-прежнему берёт все физические
ядра (не больше 8). Ручная настройка потоков уважается для обеих стадий.

**Отчёт о прогоне в отдельном окне.** В развёрнутой карточке записи
осталась кнопка «Отчёт о прогоне», сам отчёт открывается широким
моноширинным текстом — больше не переносится по слову на строку.

**Сохранение отчёта через окно Windows.** «Сохранить отчёт в файл»
открывает обычное окно «Сохранить как…» и показывает путь к файлу.

**Единая формулировка скорости.** В таблице, карточке и шапке записи
скорость показана одинаково: «×3.58 — быстрее реального времени».

**«Авто» использует все физические ядра**, привязка к быстрым ядрам
выключена по умолчанию — на гибридных процессорах это заметно быстрее.
